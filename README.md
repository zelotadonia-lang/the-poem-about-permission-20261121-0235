A small Python program that writes one short poem about agency, the power to ask and to be given, to `/output/entry.txt`. The poem is 158 characters: a door that unbars itself, a key to a door never owned, a room that was always ours.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
